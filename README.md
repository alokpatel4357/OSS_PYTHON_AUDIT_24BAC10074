## Repository Contents
This repository contains shell scripts and report for the Open Source Software Audit project.

## Scripts Description

### Script 1 — System Identity Report
Displays Linux distribution, kernel version, logged-in user, home directory, uptime and date.

### Script 2 — FOSS Package Inspector
Checks whether Python is installed, shows version and license information.

### Script 3 — Disk and Permission Auditor
Shows permissions, owner and disk usage of important Linux directories.

### Script 4 — Log File Analyzer
Counts keyword occurrences in a log file and displays last 5 matching lines.

### Script 5 — Open Source Manifesto Generator
Asks user questions and generates a manifesto text file.
